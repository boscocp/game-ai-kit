## Demo by demo {#by-demo}

- <a id="run"></a>**Checkers**, `make run` -- like checkers, you against the computer.
  - keys: space plays white's move; 1-6 how far it looks; E swaps its evaluation for the learned one.
  - techniques: ● [ai_adversarial](ai_adversarial.md), ○ [ai_learning](ai_learning.md) (declared in its manifest, never reached from its scene), ● [Learned evaluation](learned_evaluation.md).
- <a id="demo-skirmish"></a>**The skirmish**, `make demo-skirmish` -- like a small Advance Wars battle.
  - keys: space ends your turn; each blue unit then says what it decided, and the probability it decided on.
  - techniques: ● [ai_learning](ai_learning.md), ● [ai_search](ai_search.md).
- <a id="demo-tictactoe"></a>**Noughts and crosses**, `make demo-tictactoe` -- like tic-tac-toe, against Michie's matchbox machine.
  - keys: space draws MENACE's bead; 1-4 its age; M what perfect play makes of each square.
  - techniques: ● [MENACE](menace.md).
- <a id="demo-search"></a>**Four searches**, `make demo-search` -- like the click-to-move of any strategy game, slowed down to one cell at a time.
  - keys: 1-4 choose the search; space reveals the next cell it expanded; B the next board.
  - techniques: ● [ai_search](ai_search.md).
- <a id="demo-stealth"></a>**Stealth**, `make demo-stealth` -- like the top-down stealth of the first Metal Gear.
  - keys: space waits, and each guard's cone and suspicion move on; D shows the danger map.
  - techniques: ● [ai_fuzzy](ai_fuzzy.md), ● [ai_perception](ai_perception.md), ● [ai_search](ai_search.md).
- <a id="demo-steering"></a>**Steering**, `make demo-steering` -- like the enemies of an action game chasing and stopping, one force at a time.
  - keys: click moves a target; space pauses; . one step.
  - techniques: ● [ai_steering](ai_steering.md).
- <a id="demo-racing"></a>**Racing**, `make demo-racing` -- like Micro Machines, seen from above, the AI in the same car as yours.
  - keys: 1-3 the AI's level; Tab watches the three AIs race.
  - techniques: ● [ai_steering](ai_steering.md), ● [The racing driver](racing_driver.md).
- <a id="demo-racing3d"></a>**Racing in 3D**, `make demo-racing3d` -- like Gran Turismo, on tyres that slip.
  - keys: 1 PID, 2 heat line, 3 measured grip -- each on or off; Tab watches the next car.
  - techniques: ● [ai_steering](ai_steering.md).
- <a id="demo-infiltration"></a>**Infiltration**, `make demo-infiltration` -- like Metal Gear Solid, in third person.
  - keys: 1-5 switch each part of the guards' reasoning; Tab follows the next guard.
  - techniques: ● [ai_fuzzy](ai_fuzzy.md), ● [ai_perception](ai_perception.md), ● [ai_search](ai_search.md), ● [ai_teamwork](ai_teamwork.md).
- <a id="demo-botmatch"></a>**Bot match**, `make demo-botmatch` -- like a bot match in Unreal Tournament or Counter-Strike.
  - keys: 1-3 blue's claims, commander and retreat; Tab a bot; T take it over; M the map.
  - techniques: ● [ai_perception](ai_perception.md), ● [ai_search](ai_search.md), ● [ai_teamwork](ai_teamwork.md).
- <a id="demo-behaviour"></a>**One guard, four ways to decide**, `make demo-behaviour` -- like a guard on its rounds, as in Metal Gear or Thief.
  - keys: 1-4 swap the state machine, the behaviour tree, GOAP and HTN mid-round; space a turn.
  - techniques: ● [ai_behaviour](ai_behaviour.md), ◐ [ai_fuzzy](ai_fuzzy.md) (through `stealth`), ● [ai_perception](ai_perception.md), ● [ai_search](ai_search.md).
- <a id="demo-rts"></a>**Real-time strategy**, `make demo-rts` -- like StarCraft or Age of Empires, against a commander that plans.
  - keys: V watches two computers; H the planner; I the influence map; F lifts the fog.
  - techniques: ● [ai_behaviour](ai_behaviour.md), ● [ai_planning](ai_planning.md), ● [ai_rts_core](ai_rts_core.md).
- <a id="demo-tactical"></a>**Tactics**, `make demo-tactical` -- like Advance Wars.
  - keys: C changes the computer; its next decision is drawn in pink before space plays it; S swaps sides.
  - techniques: ● [ai_behaviour](ai_behaviour.md), ● [ai_learning](ai_learning.md), ● [ai_planning](ai_planning.md).
- <a id="demo-fighting"></a>**Fighting, training mode**, `make demo-fighting` -- like Street Fighter's training mode, against a dummy that learns you.
  - keys: M cycles the dummy's mode; space one frame; P pause.
  - techniques: ● [ai_learning](ai_learning.md), ● [ai_opponent](ai_opponent.md), ● [Behaviour cloning](behaviour_cloning.md).

## How the marks are measured {#how}

A mark is measured, not written. The catalogue starts from the techniques a demo's manifest declares (`depends_on` in `modules/<example>.json`, directly or through another example it uses), and follows the code from the scene its `make` target opens -- every class name and every `res://` path, file by file, tests left out:

- ● the demo's own code reaches the technique;
- ◐ only another example's code reaches it, and the line names which;
- ○ the demo's manifest declares it and nothing its scene reaches uses it: the dependency belongs to code the demo does not run -- the Python that trains it, or a file the scene never loads.

A technique that lives in Python and a demo rather than in an addon (`non_module_techniques.json`) is marked ● on the demos that file names, and `make lint-catalogue` fails when such a demo's scene never reaches the technique's Godot code. The known game and the keys come from `games.json`, the one hand-written input; `make menu` opens every demo here.
